# 0001 Profile content comes from a GitHub scan

Status: Accepted

## Context

The profile page was a neon frame with almost no work in it. Nour asked for an arcade look and the real detail of what he does. He said to take that detail from GitHub: the profile and every public repo.

## Decision

The profile README is filled from a scan of `nourmamdouhdev` on GitHub. That includes the profile fields, every public repo, and the text inside those repos. A fork is labeled as a fork. If a README names another author, that is said in plain words. The arcade look is the frame. There is no game on the page.

## Consequences

The page can only claim what GitHub already shows. Two sources disagree today: the profile company is Systemize, and the portfolio repo says Digital Experts Marketing. Both stay visible until Nour picks one. New work does not appear until it is on GitHub and the page is scanned again.
